## 2.3.0
- Обновление sing-box: если новая версия не принимает конфиг из-за устаревших полей, панель сама переводит их в новый формат (DNS-серверы address → type, dns-правила с outbound → domain_resolver, поля tun inet4_*, sniff/domain_strategy во входах, outbound block/dns → действия reject/hijack-dns), проверяет результат новой версией и показывает список изменений. Конфиг записывается только при установке, прежний сохраняется; если служба не поднимется, возвращаются и бинарник, и конфиг

- «Настройки → Конфиг → Совместимость»: кнопка «Перевести устаревшие поля в новый формат» для установленной версии (с предпросмотром изменений)
